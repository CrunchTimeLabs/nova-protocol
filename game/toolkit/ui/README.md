# ui

## Propósito
Utilidades de dibujo genéricas: texto, paneles, tarjetas, barras y colores de espectro (en gris).

## Escenarios
- DADO un `CanvasItem` CUANDO se llama a `UiDraw.panel`, `card` o `bar` ENTONCES dibuja formas planas sin sombras ni bordes redondeados.

## Qué reutilizar
- `UiDraw`.

## Depende de
Nada.

## Cubierto por
`features/expedition`.
