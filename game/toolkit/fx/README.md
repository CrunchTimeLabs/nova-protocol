# fx

## Propósito
Efectos visuales. En este proyecto están reducidos a stubs sin estética para conservar la interfaz.

## Escenarios
- DADO una pantalla que pide estrellas, partículas o un planeta CUANDO usa estas clases ENTONCES no se dibuja nada decorativo (planeta = círculo plano).

## Qué reutilizar
- `Starfield`, `Bursts`, `PlanetView` (solo por compatibilidad con `features/expedition`).

## Depende de
Nada.

## Cubierto por
`features/expedition`.
